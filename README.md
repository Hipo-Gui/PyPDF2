# pypdf2-manipulation

Projeto em Python utilizando a biblioteca **PyPDF2** para manipulação de arquivos PDF.

O código demonstra leitura, escrita, divisão de páginas e mesclagem de arquivos PDF, utilizando `PdfReader`, `PdfWriter` e `PdfMerger`.

---

## Funcionalidades

- Leitura de arquivos PDF
- Extração de páginas individuais
- Escrita de novos arquivos PDF
- Mesclagem de múltiplos PDFs em um único arquivo

---

## Estrutura

- PDFs originais são carregados a partir de um diretório base
- Páginas são extraídas e salvas individualmente
- Arquivos gerados podem ser reorganizados e unidos em um único PDF final

---

## Dependências

- Python
- PyPDF2
